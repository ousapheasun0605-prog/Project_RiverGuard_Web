# Project RiverGuard

## Project Overview
RiverGuard is an autonomous river-cleaning robot system designed to collect floating waste, monitor robot operations, record mission footage, and support AI-based waste classification.

## Technology Stack
- Frontend: React and Vite
- Backend: FastAPI and Python
- Database: PostgreSQL
- Communication: MQTT and WebSocket
- Computer Vision: OpenCV and YOLOv5
- Robot software: ROS 2 and ESP32 integration

## Repository Structure
- `Frontend/` — Web dashboard and user interface.
- `Backend/` — Backend APIs, authentication, database, MQTT, and WebSocket services.
- `robot/` — Robot firmware and hardware integration.
- `ai/` — AI processing and waste classification.
- `docs/` — Project documentation.

## Team Workflow
Feature branches are merged into `develop` for integration and testing. Stable versions are merged into `main`.

## Project Status
RiverGuard is currently under development. Features and integrations are being implemented and tested.
